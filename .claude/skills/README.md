# skills

Reusable domain knowledge for Claude Code, added per-phase as the project
plan calls for it — not scaffolded in ahead of time.

Each skill should be self-contained: instructions, references, and examples
for one specific kind of task (e.g. "how this repo writes Prisma
migrations", "how to add a new NestJS module"), added when that knowledge is
actually needed rather than speculatively up front.
